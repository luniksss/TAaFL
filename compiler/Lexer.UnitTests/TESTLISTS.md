# Список тестов лексического анализатора для языка МЯУ#
## Числовые литералы:
- [x] Целое число(положительное): `215`
- [x] Ноль: `0`
- [x] Дробное число(положительное): `3.14`
- [x] Дробный ноль: `0.0`
- [x] Число с ведущим нолем: `0215`
- [x] Отрицательное число + отрицательное дробное число: `-0.314 -255` (минус разбивается на отдельный токен MinusSign)
## Идентификаторы:
- [x] Идентификатор: `number`
- [x] Русский идентификатор: `переменная1`
- [x] Идентификатор с начальным подчеркиванием: `_number`
- [x] Идентификатор с цифрами и подчеркиванием: `number_15integer`
- [x] Регистронезависимые ключевые слова: `МяУ строгийМУР царапнуть`
- [x] Регистронезависимые идентификаторы: `IS_IT_NUMber is_it_number`
## Выражения:
- [x] Простое выражение, сложение: `1 + 5 - 3`
- [x] Простое умножение: `a * b`
- [x] Простое сравнение: `10 < 5`
## Комментарии:
- [x] Комментарий в начале строки: `окак Удалить после рефакторинга!`
- [x] Комментарий после кода: `мур цыфорка number1 15 окак Буферная переменная`
## Ошибочные лексемы:
- [x] Ошибочное число: `15abc`
- [x] Ошибочный идентификатор: `15number`
## Строковые литералы:
- [x] Простой строковый литерал: `"text text 123 aaa__"`
- [x] Строковый литерал с экранированием: `"text \n \\ \""`
- [x] Строковый литерал с табуляцией: `"text \t abc"`
