# Список тестов синтаксического анализатора Kaleidoscope
## Разбор выражений
 - [] Базовые арифметические операции : 10 + 5 - 2
 - [] Сложные операций с унарным минусом : -10 - 5 - -5  
 - [] Умножения и деление : 10 * 5 / 2
 - [] Остаток от деления : 10 % 2
 - [] Тест деления : 6 / 5
 - [] Разбор арифметических выражений с учётом приоритета: 1 + 2 * 3 → 7
 - [] Тест приоритета скобок : (2 + 3) / 10
 - [] Разбор выражений со сравнениями и арифметикой: 1 + 2 < 5 → 1
 - [] Разбор выражения с множественными скобками: ((1 + 2) * (3 - 1)) - 2 → 4
 - [] Приоритет унарного минуса и степени : (-2) ** 10, -(2 ** 10)
 - [] Многократное логического отрицания : not not true
 - [] Тест приоритета операций умножения : 3 + 4 * 5 == 3 + (4 * 5)
 - [] Тест операции неравенства : 312 != 31
 - [] Объявление константы: строгиймур pi 3.14159 мяу 4.0 * pi * 4.0 мяу → [3.14159, 50.26544]
 - [] Булевые значения, как числа : false == 0, true == 1
 - [] Комплексный приоритет операций : 2 + 3 * 4 ** 2
 - [] Ассоциативность деления и умножения : 10 / 2 * 5 + 3
 - [] Сравнение целых и дробных чисел : 5 == 5.0, 5 == 5.1
 - [] Разбор if ... else if ... else
 - [] Разбор цикла while, изменяющего переменную
 - [] Разбор функции с одним аргументом и её вызова
 - [] Разбор функции без аргументов и её вызова
 - [] Разбор функции с двумя аргументами и её вызова
 - [] Рекурсивный вызов функции с одним аргументом
## Негативные сценарии
Эти сценарии должны бросать исключение:
 - [] Использование переменных без объявления: x + 1
 - [] Использование переменной без его объявления
 - [] Параметры функции должны иметь разные имена
 - [] Нельзя вызвать функцию с числом аргументов, отличным от числа параметров
 - [] Нельзя объявить функцию, константу и переменную с одинаковым именем
