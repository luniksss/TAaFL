### Программы

 - [X] Тест объявления переменной : `мур цыфорка x царапнуть 1 мяу`
 - [X] Тест объявления переменной без инициализации : `мур цыфорка x мяу`
 - [X] Тест объявления константы : `строгиймур цыфорка y царапнуть 10 мяу`
 - [X] Тест присваивания переменной : `x царапнуть 5 мяу`
 - [X] Тест переменных и констант, объявление и вывод : `мур цыфорка x царапнуть 1 мяу строгиймур цыфорка y царапнуть 10 мяу мур цыфорка t мяу мурлыкать(x + y) мяу`
 - [X] Тест ввода в переменную : `клацать(x) мяу`

#### Условные операторы
 - [X] Тест условного оператора if : `триппитроппа (x > 0) { мурлыкать(x) мяу }`

#### Главная функция
 - [X] Тест главной функции : `лапкапомощи() { мурлыкать(42) мяу }`

#### Синтаксические ошибки
 - [X] Ошибка — объявление переменной без точки с запятой : `мур цыфорка value царапнуть 0`
 - [X] Ошибка — присваивание константе : `строгиймур цыфорка x царапнуть 5 мяу x царапнуть 10 мяу`
 - [X] Ошибка — использование необъявленной переменной : `x царапнуть 5 мяу`
 - [X] Ошибка — дублирование имени переменной : `мур цыфорка x царапнуть 1 мяу мур цыфорка x царапнуть 2 мяу`
 - [X] Ошибка — конфликт имени константы и переменной : `строгиймур цыфорка x царапнуть 1 мяу мур цыфорка x царапнуть 2 мяу`
