# Грамматика программы на языке МЯУ#
## 1. Примеры кода
```
мур цыфорка счетчик царапнуть 0 мяу
магасияй (счетчик <= 5) {
  мурлыкать(счетчик) мяу
  счетчик += 1 мяу
}
```

## 2. Ключевые особенности и семантические правила языка
- язык регистронезависимый  
- операции сложения, умножения, вычитания, деления, сравнения и возведения в степень двух значений разрешена только если оба значения имеют один тип

### 1. Структура программы
Код программы начинается с самого начала файла и до самого его(файла) конца. То есть, язык следует функциональной парадигме — в нём программа состоит из выражений и объявлений функций/констант  
- Нет объявления начала и конца программы, но есть объявление функции - `лапка`
- Точка начала выполнения функций - главная функция (типо main(), но называется `лапка помощи` или `лапка ведущая`(как ведущая нога у человека, с которой он начинает бежать))

### 3. Переменные и константы
Язык поддерживает как изменяемые(`мур`), так и неизменяемые переменные(`строгиймур`).  
Переменные объявляются явно, доступ к необъявленной переменной считается ошибкой(повторное объявление той же переменной тоже обычно ошибка)

### 4. Ввод/Вывод
Ввод-вывод происходит с помощью инструкций с ключевыми словами:  
- ввод - `клацать`, например
  ```
  мур нитка цитата мяу
  клацать(цитата) мяу
  ```  
- вывод - `мурлыкать`, например
  ```
  триппитроппа (цитата == "на тебе рыбку") {
  мурлыкать "вот это по-нашему!" мяу
  }
  ```
Возможен лишь вывод переменной или константы с типом строка/число(целое или действительное)/булевое значение, конкретной строки/числа/булевого значения

### 5. Виды инструкций
**Не любое** выражение является инструкцией.  
Есть отдельные инструкции объявления переменных и/или констант, а также для чтения и печати.  
Присваивание не является выражением, но является инструкцией. То есть присваивание не вернет никакое значение

### 6. Виды инструкций
В языке есть символ-разделитель - `мяу`, который является аналогом `;`

## 4. Грамматика в виде блока кода на языке EBNF
```
// Структура программы
program = { valueDeclaration | functionDeclaration }, mainFunction, { valueDeclaration | functionDeclaration };
mainFunction = "лапка помощи", "(", ")", block;
functionDeclaration = "лапка", identifier, "(", [ parameterList ], ")", [":", type], block;
functionCall = identifier, "(", [ argument_list ], ")", instructionDelimiter;

argument_list = identifier, { ",", identifier };
parameterList = parameter, { ",", parameter };
parameter = type, identifier;
block = "{", { statement }, "}";

// Переменные и константы
valueDeclaration = (variableDecl | constantDecl), instructionDelimiter;
variableDecl = "мур", type, identifier, [ "царапнуть", expression ], instructionDelimiter;
constantDecl = "строгиймур", type, identifier, "царапнуть", expression, instructionDelimiter;

// Виды инструкций
statement = variableDecl |
    constantDecl |
    assignment |
    inputStatement |
    outputStatement |
    ifStatement |
    whileStatement |
    returnStatement |
    functionCall |
    block
);

assignment = identifier, "царапнуть", expression, instructionDelimiter;
inputStatement = "клацать", "(", identifier, ")", instructionDelimiter;
outputStatement = "мурлыкать", expression, { ",", expression }, instructionDelimiter;
ifStatement = "триппитроппа", "(", expression, ")", block, [ elseStatement ];
elseStatement = "троппатриппа", "{", { statement }, "}" ;
whileStatement = "магасияй", "(", expression, ")", block;
returnStatement = "вернуть", [ expression ], instructionDelimiter;

instructionDelimiter = "мяу";
```
