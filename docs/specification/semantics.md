# Спецификация правил семантики
## Области видимости
1) В языке используется лексическая область видимости  
2) Область видимости образуется внутри функции    
3) Функция захватывает переменные внешней области видимости лишь в случае, если они были переданы ей в качестве параметров
4) Ветвления и циклы захватывают лишь переменные из функции, в которой они были объявлены
5) Вне своей области видимости переменная **недоступна**, но ее имя зарезервировано  

## Уникальность имен
1) Имя уникально в 1 программе, независимо от области видимости
2) Переменные и функции используют общее пространство имен - нельзя назвать функцию именем, уже забронированным переменной и наоборот
3) В языке нет встроенных функций, но есть встроенные константы, именами которых нельзя называть ни переменные, ни константы, ни функции программы
4) Имя встроенного типа данных нельзя скрыть своей переменной или функцией. Ключевые слова языка забронированы, и их использование в качестве наименования запрещено

## Параметры функций
_Семантика формальных и фактических параметров_  
1) Параметры в функцию передаются по значению  
2) Параметр нельзя скрыть локальной переменной
3) Параметру нельзя присвоить значение внутри функции
4) Не допускается несовпадение числа формальных и фактических параметров
5) Выражения, указанные в качестве фактических параметров, вычисляются слева направо
6) Функция может заканчиваться без оператора return(`вернуть`), если у функции не объявлен тип возвращаемого значения, либо это тип void(`ничего`)

## Рекурсия 
_Семантика рекурсии и взаимной рекурсии функций_  
Рекурсия не поддерживается  

## Ветвления
1) Условие записывается в скобках после ключевого слова `триппитроппа`.
2) Условие ветвления возвращает тип `кринжли`, где истинное значение - `кринж`, ложное - `некринж`    
3) Если условие истинно, то выполняется код, который идет в фигурных скобках после `триппитроппа`  
4) Если условие ложно, то либо выполняется код, который идет после `троппатриппи`, либо, если этого блока кода нет, то не выполняется ничего
5) Блок else(`троппатриппи`) относится к ближайшему if(`триппитроппа`)  
6) Аналога switch..case нет

## Циклы
1) Цикл while(`магасияй`) работает до тех пор, пока условие не станет `некринж`, либо будет выполнена инструкция break(`стоп`), если она есть в теле цикла
2) В языке есть цикл for(`хвостомкрутить`), и он работает, пока условие не станет ложным, либо если будет выполнена инструкция break(`стоп`)
3) Инструкция break может быть лишь внутри цикла while(`магасияй`), for(`хвостомкрутить`), do while(`хотябыраз магасияй`)
4) Инструкция continue не поддерживается языком
5) Выражение в условии цикла должно возвращать тип  `кринжли`, где истинное значение - `кринж`, ложное - `некринж`
   
## Прочие правила
1) Нельзя считать значение неинициализированной переменной
2) Нельзя переприсваивать значение константной переменной
