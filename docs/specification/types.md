# Типы данных в языке МЯУ#
## Краткое описание	
_Список типов данных_  
- ничего - "пустой"(void)
- цыфорка - целочисленное значение(int)
- рилцыфорка - действительное значение(float)
- кринжли - булевое значение (bool)
    - кринж - true
    - некринж - false
 
Примеры программ можно посмотреть в файле codeExamples.md  
  
_Ключевые принципы каждого из возможных типов:_  
### Целочисленный тип
1) Целочисленный тип вмещает 4 байта(32 бита).  
2) Целое число можно преобразовать в тип `рилцыфорка` путем добавления дробной части с помощью функции `мягколапка()`   

### Числа с плавающей точкой
1) Вещественный тип вмещает 4 байта(32 бита) - около 6-7 значащих цифр (формат IEEE 754 binary32 (как float в C#)).  
2) Вещественное число можно преобразовать в тип `цыфорка` путем отбрасывания дробной части с помощью функции `твердолапка()`  

### Булев тип данных
1) short-circuit evaluation не поддерживается в этом языке
2) Нельзя преобразовать число в булев тип.
3) Для вывода булева типа необходимо использовать функцию вывода текста - `мурлыкать`:
```
мурлыкать(кринж) мяу <-- ВЫВЕДЕТ кринж

мур кринжли являетсяЧислоПоложительным царапнуть некринж мяу
мурлыкать(являетсяЧислоПоложительным) мяу <-- ВЫВЕДЕТ некринж
```
4) Для ввода значения для булевой переменной с консоли пользователь должен ввести:  
  a) 0 для присваивания переменной значения "некринж"  
  b) 1 для присваивания переменной значения "кринж"  

## Литералы	
_Описание литералов для всех типов данных_  
Целочисленные: без префикса(десятичные числа) - `'0'..'9'`  
Числа с плавающей точкой: `{'0'..'9'} + '.' + {'0'..'9'}`  
Булев тип данных: два логических литерала: `кринж` и `некринж`.

## Операторы	
_Семантика операторов для всех типов данных_  
Какие операторы поддерживаются каждым из типов:  
| оператор | цыфорка | рилцыфорка | кринжли |
| ----- | --------- | --------- | --------- |
| унарные + и - | да | да | нет |
| возведение в степень | да | да | нет |
| умножение * | да | да | нет |
| деление нацело / | да | да | нет |
| остаток от деления % | да | да | нет |
| (не-)строгое больше | да | да | нет |
| (не-)строгое меньше | да | да | нет |
|нестрогое равенство(==) | да | да | да |
|неравенство (!=) | да | да | да |
|логическое И | нет | нет | да |
|логическое ИЛИ | нет | нет | да |
|логическое НЕ | нет | нет | да |

## Переменные	
_Семантика объявлений и присваиваний переменных_  
При объявлении переменной необходимо обязательно указывать ее тип. Изменить тип переменной присваиванием невозможно.  
Можно проинициализировать переменную при создании:
```
мур цыфорка число1 мяу
мур цыфорка первоеСлагаемое царапнуть 0 мяу
мур цыфорка первоеСлагаемое царапнуть 0.12 мяу  <-- ОШИБКА

мур рилцыфорка радиус мяу
мур рилцыфорка дефолтныйРадиус царапнуть 3.14 мяу
мур рилцыфорка дефолтныйРадиус царапнуть дефолтР мяу  <-- ОШИБКА

мур кринжли являетсяЧислоПоложительным мяу
мур кринжли являетсяЧислоПоложительным царапнуть некринж мяу
мур кринжли являетсяЧислоПоложительным царапнуть 1.23 мяу <-- ОШИБКА
```
В языке МЯУ# **не разрешены** неявные **преобразования**. Но разрешены явные преобразования целых чисел в действительные и наоборот с помощью внутренних функций.  Тип переменной определяется лишь 1 раз(в момент её создания) и не может быть преобразован каким-либо способом.
